# Minesweeper

A classic Minesweeper game built with React and TypeScript.

## Features

- 10x10 grid with 20 mines
- Left-click to reveal cells
- Right-click to flag suspected mines
- Flood-fill reveals empty regions
- First click is always safe (mines placed after)
- Win/lose detection with reset button

## Tech Stack

- React 19
- TypeScript
- Vite

## Getting Started

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

## Legacy

The original vanilla JavaScript implementation is preserved in the `legacy/` folder.
